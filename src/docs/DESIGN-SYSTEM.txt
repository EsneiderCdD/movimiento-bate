  2. ESTILO TIPOGRAFICO
================================================================================

--------------------------------------------------------------------------------
  Grosor (font-weight)
--------------------------------------------------------------------------------

  400  - Anton headings (peso unico cargado)
  500  - Oswald (cargado), Barlow (cargado)
  600  - Labels, tags, roles, form labels, botones secundarios
  700  - Block titles, submit buttons, CTA buttons, modal title

--------------------------------------------------------------------------------
  Letter-spacing
--------------------------------------------------------------------------------

  Valor     Contexto
  --------  -------------------------------------------------------------
  3px       Labels, tags, roles (desktop)
  2px       Labels, tags en mobile (600px)
  1.5px     Block titles, CTA buttons, submit buttons, ecommerce btn, modal
  1px       Form labels, upload button, ProductCard button
  0.5px     Titulos principales (Anton display)

--------------------------------------------------------------------------------
  Text-transform
--------------------------------------------------------------------------------

  Todo el texto UI basado en Oswald usa: text-transform: uppercase

  1.5       Subtitulos en mobile, ProductCard descripcion
  1.55      Hero subtitulo (base)
  1.6       SectionHeader / DenunciaCta / Modal subtitulos
  1.7       QuienSoy bio parrafos

================================================================================
  4. RESPONSIVIDAD - BREAKPOINTS
================================================================================

El proyecto usa media queries custom (no Tailwind). Todos los valores son max-width
salvo indicacion contraria.

  Breakpoint   Uso principal
  ----------   -------------------------------------------------------------
  1500px       Reduccion inicial de titulos (80->64px hero, 56->48px seccion)
  1250px       Segunda reduccion de titulos, ajuste de padding
  1024px       Tienda: grid de 3 a 2 columnas
  1001px       EcommerceHero: carousel se convierte en grid estatico 3 col
  1000px       Hero: 100vh -> auto, cambia imagen desktop -> mobile
  768px        QuienSoy: grid 2 col -> 1 col, sin sticky
  750px        Reduccion de padding y subtitulos, scroll indicator oculto
  640px        Denuncia form: grid -> 1 col, tienda: 2 -> 1 col
  600px        Labels/tags a 11-12px, letter-spacing apretado, CTA full-width
  450px        Reduccion adicional padding/fonts, flechas mas pequenas
  350px        Breakpoint minimo: titulos 20-28px, tags 10px

--------------------------------------------------------------------------------
  Contenedores max-width
--------------------------------------------------------------------------------

  Valor        Contexto
  ----------   -------------------------------------------------------------
  1920px       .frame contenedor exterior (globals.css)
  1240px       Grid productos / contenedor Ecommerce
  1080px       Contenedor QuienSoy
  820px        Contenedor formulario Denuncia
  720px        Contenido Hero, SectionHeader, DenunciaCta
